# 📚 Portal do Aluno SENAI

## 📖 Descrição do Projeto

O *Portal do Aluno SENAI* é uma aplicação web desenvolvida com o objetivo de simular um sistema de cadastro de alunos para cursos oferecidos pelo SENAI. O projeto foi criado utilizando HTML5, CSS3, JavaScript, Bootstrap 5 e SweetAlert2, seguindo boas práticas de usabilidade, acessibilidade digital e experiência do usuário.

A plataforma apresenta uma interface moderna, responsiva e acessível, permitindo que os usuários realizem seu cadastro de forma simples e intuitiva.

---

## 🎯 Objetivo

Desenvolver uma página inicial funcional para o Portal do Aluno SENAI, oferecendo:

* Cadastro de alunos para cursos;
* Interface responsiva para diferentes dispositivos;
* Recursos de acessibilidade digital;
* Validação de formulários;
* Feedback visual através do SweetAlert2;
* Navegação intuitiva e agradável.

## 📋 Funcionalidades

### Cabeçalho

* Logo/Título "Portal do Aluno SENAI";
* Menu de navegação responsivo utilizando Bootstrap.

### Banner Principal

* Título de destaque;
* Texto explicativo sobre o portal;
* Botão "Realizar Cadastro".

### Formulário de Cadastro

Campos disponíveis:

* Nome Completo;
* E-mail;
* Telefone;
* Curso Desejado (Select);
* Turno (Radio Button);
* Aceite dos Termos (Checkbox).

### Validações

* Verificação de campos obrigatórios;
* Validação do aceite dos termos;
* Mensagens de erro e sucesso utilizando SweetAlert2.

### Recursos de Acessibilidade

* Plugin VLibras integrado;
* Botão de Alto Contraste;
* Botão para aumentar fonte;
* Botão para diminuir fonte;
* Estrutura HTML semântica;
* Foco acessível em elementos interativos;
* Labels e descrições adequadas para formulários.

### Responsividade

* Compatível com:

  * Computadores;
  * Tablets;
  * Smartphones.

## ♿ Acessibilidade

O projeto foi desenvolvido pensando na inclusão digital.

Recursos implementados:

* Tradução para Libras através do VLibras;
